#🎪 Sonata's Website
Welcome to the official website dedicated to the interactive universe and characters! For example the upcoming (no time soon) animated project "The Grand Circus"!

#🌐 Live Website (Netlify): (https://sonatafandominfo.netlify.app/)

#✨ Features
🎭 Interactive Character Gallery: Browse detailed character cards featuring custom bios, artwork, and unique alerts.
🔍 Category Filtering: Effortlessly filter characters by their roles in a single click without resetting the gallery state.
🎨 Responsive & Stylish Design: Colourful aesthetic custom-tailored to fit the atmosphere of the show.
#🛠 Tech Stack
HTML5 — Page structure and semantics.
CSS3 — Custom styling, flexible layouts (Flexbox/Grid), glowing highlights, and hover effects.
JavaScript (Vanilla JS) — Interactive gallery logic, dynamic character filtering, keyboard event listeners (keydown), and custom alert handling.
